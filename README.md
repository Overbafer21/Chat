# Two-Way Colorful Chat Messenger

Небольшой desktop-проект на Java Swing: одно окно, два независимых пользователя и мгновенный обмен сообщениями внутри приложения.

## Что изменено в дизайне

- Добавлен современный "card"-интерфейс с закруглёнными панелями для каждого пользователя.
- Фон окна заменён на мягкий градиент.
- Обновлена типографика и отступы для более чистого визуального стиля.
- Кнопки `Send` получили контрастные цвета для каждой стороны.
- Сообщения теперь отправляются с отметкой времени (`HH:mm`).

## Функциональность

- Два чата (User 1 и User 2) в одном окне.
- Отправка по кнопке `Send`.
- Отправка по `Enter`.
- Перенос строки по `Shift + Enter`.
- Автопрокрутка чата к последнему сообщению.

## Структура проекта

```text
src/
  TwoWayColorfulChat.java
```

## Как запустить

Требуется JDK 11+.

```bash
javac -d out src/TwoWayColorfulChat.java
java -cp out TwoWayColorfulChat
```
